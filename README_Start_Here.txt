INTERVIEW-IQ PROJECT KIT (no install, works with Northeastern's Claude)
MGT4850 Business Strategy - G. Bradley Scheller

You do NOT need code execution or Skills. The Robotaxi case and the full interview plan
are already built in. About 5 minutes, once.

1. Unzip this kit. It has two files you will use:
   Interview-IQ_Project_Instructions.txt and Interview-IQ_Robotaxi_Knowledge.md
2. In Claude, open Projects and click New project. Name it: Interview-IQ Robotaxi
3. In the Project, click Instructions (sometimes "Set project instructions").
   Open Interview-IQ_Project_Instructions.txt, copy ALL of it, paste it in, and save.
4. In the Project's Knowledge (or Files) area, click + and upload Interview-IQ_Robotaxi_Knowledge.md
5. Start a new chat inside the Project and type: Run Interview-IQ

If your Claude can make artifacts, Interview-IQ also opens an Interview-IQ Dashboard beside the
chat (plan, coverage map, current question, progress). If not, everything appears in the chat.

Saving your progress: at each checkpoint, Interview-IQ prints your Interview-IQ Log in one block.
Copy it into a text file named "Interview-IQ Log.txt" and add it to the Project's Knowledge,
replacing the older one. Any new chat in the Project can then pick up where you left off (choose B).

Interview-IQ never writes your memo. It runs your interviews, keeps the evidence, and gives you
a memo template and draft exhibits. The analysis is yours.
